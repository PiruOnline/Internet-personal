Preguntas frecuentes

Todo lo que necesitás saber antes de comprar.

¿Cómo compro un plan? +

Elegí el plan que querés, presioná Comprar y agregalo al carrito. Después completá tus datos y seguí el proceso de pago.

¿Cómo realizo el pago? +

El pago se realiza mediante Mercado Pago utilizando nuestro enlace de pago.

¿Cómo recibo mi compra? +

Una vez realizado el pago, enviá el comprobante por WhatsApp para que podamos procesar tu pedido.

¿Qué aplicación necesito? +

Para CGLite necesitás la aplicación CGLite. Para los planes correspondientes necesitás HTTP Custom.

¿Puedo comprar más de un plan? +

Sí. Podés agregar varios planes al carrito antes de realizar el pago.

¿Cómo contacto con soporte? +

Podés comunicarte directamente mediante WhatsApp desde la página.
