PREGUNTAS

Preguntas frecuentes

Algunas respuestas antes de contratar.

¿Cómo compro un plan? +

Elegí el plan que querés, agregalo al carrito y luego utilizá el botón de Mercado Pago para realizar el pago. Después podés contactarnos por WhatsApp para coordinar la activación.

¿Qué aplicación necesito? +

Los planes CGLite utilizan CGLite, mientras que los planes correspondientes a HTTP Custom utilizan la aplicación HTTP Custom.

¿Puedo consultar antes de pagar? +

Sí. Si no estás seguro de qué plan elegir, podés escribirnos por WhatsApp y consultar antes de realizar el pago.

¿Cómo recibo la activación? +

Una vez realizado el pago, se coordina la activación mediante WhatsApp.

¿Qué medios de pago aceptan? +

Actualmente podés realizar el pago mediante el enlace de Mercado Pago disponible en el carrito.
